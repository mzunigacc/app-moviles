# App Móviles - Pizzería Kotlin

Actividad formativa de la Semana 2 de **Desarrollo App Móviles I (PMY2201)**.

## Descripción

Aplicación desarrollada en Kotlin para simular la operación básica de una pizzería, incluyendo gestión de clientes, productos, pedidos, inventario y repartidores.

## Funcionalidades

- Registro y validación de clientes.
- Validación de teléfono y correo electrónico.
- Gestión de productos e ingredientes.
- Cálculo de subtotal, impuestos, descuentos y total del pedido.
- Verificación y actualización automática de inventario.
- Detección de ingredientes insuficientes.
- Asignación del repartidor más cercano.
- Gestión de estados de pedidos.
- Reporte diario de pedidos.
- Clasificación de pedidos completados y pendientes.
- Manejo de valores nulos mediante null safety.
- Manejo de errores mediante `try-catch`.
- Uso de programación orientada a objetos, herencia y polimorfismo.
- Uso de colecciones `List`, `Set` y `Map`.

## Tecnologías

- Kotlin
- JDK 17
- IntelliJ IDEA

## Ejecución

Ejecutar el archivo:

`src/Main.kt`

La aplicación muestra por consola las distintas pruebas y funcionalidades implementadas.
